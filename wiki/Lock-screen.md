# Lock screen

Normally the lock screen shows the same as the home screen.

<img src="https://raw.githubusercontent.com/wiki/bornaradusin/WallpaperChanger/images/lock-screen.png" width="260" alt="Lock screen"> <img src="https://raw.githubusercontent.com/wiki/bornaradusin/WallpaperChanger/images/settings-4.png" width="260" alt="Lock screen setting">

The lock screen can also have **its own pictures and videos**, from its own albums and folders:

1. Settings → **Lock screen** → turn on **Lock screen has its own pictures and videos**.
2. On the Albums tab each album now has a **Home** and a **Lock** switch. Albums start with only **Home** on. For the lock screen's own pictures, videos or folders, put them in an album and switch only **Lock** on for it.

Under the albums, a line shows what each screen is using. A screen with no album switched on uses the other screen's albums; stills and videos from different albums are never mixed unless you switch them on for the same screen.

WallpaperChanger stays set once, for the home and lock screen together. While the phone is locked it shows the lock screen's picture or video; once you unlock, the home screen's. Both are loaded ahead of time, so the switch on unlock is instant. Only the home screen's colours are given to Android, so unlocking doesn't change the phone's colours.

Each screen keeps its own place in the rotation and its own shuffle, and both move on at each lock. Rules that switch album, and **Next album**, switch the home screen only; the lock screen keeps its own. Double-tapping the home screen only changes the home screen.

For one fixed lock screen picture (or video), use an album with just that one in it.
