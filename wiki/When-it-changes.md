# When it changes

Settings → **When to change**:

<img src="https://raw.githubusercontent.com/wiki/bornaradusin/WallpaperChanger/images/settings-1.png" width="260" alt="When to change">

| Setting | What it does |
|---|---|
| **Change wallpaper on lockscreen unlock** | A second after the screen goes off (once Android has finished locking), the next one goes up and the phone's colours change to match, while no one can see it. It's on the lock screen when you wake the phone, and nothing changes as you unlock. Turning the screen back on within that second leaves the change for the next lock. |
| **Change wallpaper every** | Off, or every 15 minutes … 24 hours. Happens while the phone is in use (not while it's asleep, as no one would see it). |
| **Change wallpaper when double-tapping on home screen** | Double-tap an empty part of the home screen. |
| **Pause rotation** | Nothing changes on its own. **Next**, the widget and rules you start by hand still work. Also on the quick settings tile. |

With the lock screen on its own rotation ([[Lock screen]]), each change moves both screens on. Double-tapping the home screen only changes the home screen.

[[Rules]] can also change it at set times, places and Wi-Fi networks.
